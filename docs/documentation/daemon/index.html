Daemon & agents

Background supervisor so work continues when the TUI is closed. Socket + pid under ~/.axi/daemon/.

shell 
$axi daemon start
$axi daemon status
$axi agents
$axi daemon stop

Tick (~2s)

  • Mark due pulses + objective backoffs
  • Deliver parent keep-going turns (pendingKick)
  • Choose-loop ticks for mission.choose left running
  • Pulse spawn children · factory DAG ticks

When up, startAgent / spawn prefer the daemon. Force local: AXI_DAEMON=0.

Agents view

/agents opens a live multi-agent TUI (daemon status, this-chat + workspace, filter, log/cancel). /agents list keeps the text board. axi agents from the shell.
