CLI reference

Quiet, cwd-based. Default command is TTY chat.

axi · axi agent

Open interactive chat in the current folder.

example 
$axi

axi ask [-y] [--json] [dir] <prompt>

One-shot answer without the chat UI.

FlagDescription
-y / --yes Auto-approve mutating tools (full-access for this ask).
--json Emit text, tools, usage, harness.
--auto / --full-access / --mode Permission mode for this ask.
example 
$axi ask "how does src/cli.ts wire commands?"
example 
$axi ask -y --json "run doctor and summarize"

axi web [--port N] [--no-open] [--detach] [dir]

Browser UI — install web deps if needed, start Next, open http://127.0.0.1:3000. See Web UI.

FlagDescription
--port N Listen port (default 3000).
--detach Background Next · print URL · exit.
--no-open Do not open a browser.
[dir] Workspace root (default: cwd).
example 
$axi web
$axi web --detach --port 3001

axi chat [list|last|<id>|new]

List or resume chats under ~/.axi/chats/.

example 
$axi chat list
$axi chat last

axi provider [list|<name>|use <name>]

List or set model providers (openai · anthropic · grok · ollama).

example 
$axi provider
$axi provider openai

axi doctor [--json] [dir]

Health check: agent, provider, workspace, skills, mcp, aq bridge.

example 
$axi doctor

axi spawn agent|list|log|cancel …

Background worker agents. Cancel requires a why (prune-with-receipt).

example 
$axi spawn agent -- "investigate flaky test"
$axi spawn list

axi daemon start|stop|status|run

Background supervisor: mission keep-going, pulse, factory, spawn host.

example 
$axi daemon start
$axi daemon status

axi mission tick|status|rebuild-index

Mark due pulses / inspect mission when chat is closed.

example 
$axi mission tick
$axi mission status

axi agents [dir] [--parent <chatId>]

Text roster of workers + daemon status. In chat, /agents opens the live TUI.

example 
$axi agents

axi version [--verbose] [--json]

Print agent version (and paths with --verbose).

example 
$axi version
