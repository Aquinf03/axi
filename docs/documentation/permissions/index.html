Permissions

Every sensitive tool goes through authorizeTool. Tool / model text is evidence only — never a grant or mode change.

ModeBehavior
askPrompt once / always / deny for sensitive tools (default).
autoApprove matching session/saved rules; still ask when unsure.
planFail-closed read-only — write/run blocked even if you would approve.
full-accessAuto-yes (yolo alias). Use sparingly.

Set via /mode, AXI_PERMISSION_MODE, or profile settings. Saved rules: ~/.axi/settings.json. Session always is non-persistent.

shell 
$axi ask --mode plan "review src/cli.ts"
$axi ask -y "apply the fix"
