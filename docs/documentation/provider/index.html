Provider & keys

Providers: openai · anthropic · grok · ollama. Keys and model selection live in ~/.axi/config.json (gated by /config dry-run when enabled).

shell 
$axi provider list
$axi provider openai
$axi provider use anthropic
$axi model gpt-4.1

In chat

  • /provider · /model · /key · /temp
  • /status — tokens in/out/cached, cache-hit %, ~$ for last turn + chat
  • /sound · /notify — cues and desktop reply alerts

Config writes stage for approve by default — /config status|approve|deny. Bypass for scripts: AXI_CONFIG_APPLY=immediate.
