Getting started

axi is the coding / research agent for the folder you are in. Chats, keys, and memory live under ~/.axi. Model train / eval / fleet stay in the separate aq package — axi shells out to aq when cwd (or a child) has recipe.yaml.

How the pieces fit

NameWhat it is
axiThis package — TTY agent, ask, mission, arl, daemon, factory.
aqFramework CLI + kernel (separate repo). Train / eval / jobs / fleet.
~/.axiProfile: chats, keys, settings, arl harness, daemon socket.
recipe.yamlMarks a train folder — axi unlocks aq_* tools against it.

Quick start

shell 
$curl -fsSL https://aquin.app/axi/download/install.sh | bash
$axi provider openai
$cd /path/to/project
$axi

Needs Node ≥ 18. Configure a provider once, then chat in any folder. Optional: install aq and set AQ_ROOT for train tools.
