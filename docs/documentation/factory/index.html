Factory

DAG of spawned subagents. Front door core/factory.ts. Persist ~/.axi/chats/<id>/factory.json — one run per chat.

chat 
$/factory run builder
$/factory status
$/factory log <node>
$/factory cancel <node> <why>

Spec shape

machine 
{ "name": "builder", "max_parallel": 2,
  "nodes": [
    { "id": "plan", "prompt": "…" },
    { "id": "impl", "needs": ["plan"], "prompt": "Use {plan}" }
  ] }
  • when — skip if guard fails
  • foreach — expand over a JSON list
  • loop — re-run until until-guard passes
  • MACHINE.md — frontmatter + fenced machine-spec JSON

Seeds: builder, review, retry-merge, review-sweep. User machines: ~/.axi/factory/machines/. Live dock paints above the composer while a run exists.
