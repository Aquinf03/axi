Chat

Interactive agent on a TTY. Chat and / menus stay in normal scrollback. Permission pickers and confirms use the alternate screen.

shell 
$axi
$axi chat last
$axi chat <id>

Composer

  • Type to chat · / opens settings / slash hints
  • While the agent is busy: type + enter queues a message; esc / ctrl-c aborts the turn (/steer)
  • /image <path> attaches an image for the next user turn
  • /copy · /url go through the host (clipboard / open URL)

Permits

Sensitive tools ask once / always / deny. plan mode is fail-closed read-only. See Permissions.

Sessions

Portable ids under ~/.axi/chats/<id>/ with workspace_root. Spawn workers are child sessions (hidden from the normal chat list).
