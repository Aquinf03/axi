Web UI

Local Next.js shell for the same agent loop as TTY chat — chat on the left, VS Code–style viewer on the right (files · Monaco · terminal).

shell 
$cd /path/to/project
$axi web
$# opens http://127.0.0.1:3000 · workspace = cwd
Needsaxi checkout (or release) with web/ · Node ≥ 18 · built dist/ (auto-built on first axi web)

Start

CommandEffect
axi webInstall web deps if needed, start Next, open the browser
axi web --detachBackground Next · print URL
axi web --port 3001Alternate port
axi web --no-openStart without opening a browser
/webFrom TTY chat — session-owned; stops when you exit chat

Workspace defaults to the current directory (AXI_WEB_WORKSPACE overrides). Chat turns use full-access for the web bridge. /web servers are tied to the TTY session; axi web --detach survives after axi exits.

Layout

  • Chat — multi-tab threads, live tool timeline, markdown replies
  • Viewer — change workspace path, open/edit files, terminal in the workspace

API (local)

RouteRole
