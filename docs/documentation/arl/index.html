arl (auto RL)

Continual harness for reusable lessons across turns — without rewriting the base personality every time. Front door core/arl.ts. Default off.

chat 
$/arl on
$/refine
$/refine --global
$/refine deploy approve

Core ideas

  • Digest — ranked [arl-digest] user row at cold boundaries (start, compact, ask)
  • Kinds — prompt · memory · rejected · skill · subagent · policy
  • Refine — plan + apply harness edits; agent schedules, host applies end-of-turn
  • Rejected — file-drawer negatives (tried + why) so dead ends are not rediscovered

Gates (defaults on)

GateSlash
Falsify — what would disprove the lesson/refine falsify
Convergent — N corroborations for global lessons/refine convergent
Deploy — stage global ship for approve/refine deploy
Preship — harness fingerprint + structural eval/refine preship
Evidence · reconcile · ledger · residual/evidence · /reconcile · /ledger · /audit

Global harness: ~/.axi/arl/. Per chat: ~/.axi/chats/<id>/arl/. Trajectory signals (/turn accept/edit/undo/retry/deny) arm auto-refine.
