Install

axi ships as an npm package with a bin/axi entry. Needs Node ≥ 18. After link, run axi doctor.

PrerequisiteNode ≥ 18 · npm · (optional) aq checkout for train tools

npm i && npm link

Install from an axi checkout and put axi on your PATH.

example 
$cd axi && npm i && npm link
$axi version
$axi doctor

axi provider <name>

Save a provider key and select it. Names: openai · anthropic · grok · ollama.

example 
$axi provider openai
$axi provider use anthropic
$axi provider list

AQ_ROOT / AQ_BIN

Point axi at an aq install so train tools work inside recipe.yaml folders.

FlagDescription
AQ_ROOT Path to the aq package (contains bin/aq).
AQ_BIN Path to the aq binary.
sibling ../aq Also discovered if axi and aq checkouts sit next to each other.
example 
$export AQ_ROOT=/path/to/aq
$axi doctor

Profile

First run creates ~/.axi. An older ~/.aq agent profile is migrated when present. Keys and settings never belong in the project tree — project .axi.json is repo-safe keys only.

~/.axi 
~/.axi/
  config.json          providers, keys, sound, notify
  settings.json        permission mode, saved rules
  chats/<id>/          messages, mission, arl, factory
  arl/                 global harness + pending deploy
  daemon/              sock, pid, log
  backups/             config dry-run backups
