Mission

Keep working when the human goes quiet — one product, four engines. Persist ~/.axi/chats/<id>/mission.json.

SlashEffect
/mission <goal>Start — sets objective + light drive
/missionStatus
/mission stopStop objective, drive, pulse, choose
/mission doneMark goal finished (ledger / residual gates apply)
/mission advancedDrive / pulse / budget power path

Engines

EngineRole
ObjectiveRe-inject + no-progress backoff · mission_done
DriveBounded keep-going + optional shell gates
PulseWall-clock wakes · durable pulse-jobs index
Chooseobserve → decide → act loop (mission.choose)

Daemon product

With axi daemon up, objective / drive / backoff kicks and choose ticks continue after the TUI closes. Continuations persist as pendingKick; the daemon runs a headless parent turn. Pulse still delivers as a spawn child. Open chat yields when the daemon is up.

shell 
$axi daemon start
$axi mission status
